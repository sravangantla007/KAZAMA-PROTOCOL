## 🌟 Executive Summary

**Kazama Protocol** is an enterprise-grade AI information architecture and digital blind spot detection platform built for the **Shinchan Online Hackathon 2026** (organized by **Devengers**) under the **Digital Dark Spot** track.

While standard search engines crawl visible text and AI summarizers blindly compress whatever is present, high-stakes decisions—such as academic admissions, competitive scholarships, legal compliance, and technical grants—frequently fail due to what is **absent, contradictory, outdated, or silently assumed**.

Kazama Protocol implements a **deterministic 4-stage pipeline (M1–M4)** combined with a **3D WebGL neural constellation**. It crawls ground truth from live internet sources and user-uploaded documents, calculates domain authority and synthetic text forensics, isolates verbatim claims, exposes cross-source contradictions, highlights unaddressed critical requirements ("digital dark spots"), and computes a mathematical **Deterministic Trust Score** with an actionable verification checklist.

## 🔍 The Problem: Why Search & Summarization Fail

Modern search and generative AI tools optimize for **positive retrieval**—they tell you what was found:
- ❌ **The Summarization Trap**: When an LLM summarizes five scattered articles, it condenses existing claims into a plausible paragraph. If all five sources neglect to mention renewal grade requirements or application fees, the summary appears complete, giving users dangerous false confidence.
- ❌ **Unflagged Contradictions**: Different websites publish conflicting deadlines, mismatched eligibility criteria, or obsolete policies without warning the reader.
- ❌ **Temporal Blindness**: Search engines rank SEO-optimized blogs from 2023 above official portals with newer 2026 guidelines.
- ❌ **Hallucinated Completeness**: Users cannot easily distinguish between a claim verified directly against primary source text versus an inference manufactured by an AI model.

## ⚙️ 4-Stage Deterministic Architecture

### Module 1: Ingestion Engine (`app/modules/ingestion.py`)
- **Multi-Source Aggregation**: Integrates the **Tavily Search API** for real-time live web crawling combined with custom user seed URLs.
- **Document Parser**: Ingests local `.pdf`, `.txt`, and `.md` files via `PyMuPDF` with metadata sanitization and fragment extraction.
- **Deduplication**: Eliminates cross-domain duplicates and strips tracking parameters to establish clean ground-truth nodes.

### Module 2: Authority & AI Forensics Weighter (`app/modules/weighter.py`)
- **Domain Authority Scoring**: Applies deterministic heuristic weights:
  - Official TLDs (`.gov`, `.edu`, `.mil`, `.ac.in`): **0.85 – 0.95**
  - Accredited Organizations (`.org`, `.int`): **0.75 – 0.85**
  - Commercial Portals (`.com`, `.net`, media): **0.50 – 0.70**
  - User Forums / Unverified Aggregators: **0.25 – 0.45**
- **AI Synthetic Text Forensics**: Evaluates lexical burstiness, perplexity variance, and robotic repetition patterns to calculate `ai_generated_probability` (0–100%).
- **Composite Trust Weight**: Blends static domain authority against AI generation penalties so synthetic spam cannot skew the decision model.

### Module 3: Synthesis & Digital Dark Spot Engine (`app/modules/synthesis.py`)
- **Verbatim Evidence Anchoring**: Claims must include exact verbatim textual excerpts from ingested sources (`quote` and `source_id`).
- **Contradiction Matrix**: Identifies cross-source disputes (e.g., Source A states deadline is March 15 while Source B states April 1).
- **Digital Dark Spot Exposure**: Queries for unaddressed, missing, or obscured requirements critical to high-stakes decisions (e.g., missing renewal requirements, unstated application costs, hidden bond conditions).

### Module 4: Decision Support Engine (`app/modules/decision.py`)
- **Deterministic Trust Scoring**: Computes a mathematical score independent of LLM hallucinations:
  $$\text{Trust Score} = w_1 \cdot \text{Source Reliability} + w_2 \cdot \text{Consensus} + w_3 \cdot \text{Time Relevance} - \text{Penalty}_{\text{dark spots}}$$
- **Readiness Classification**:
  - `GO` (Trust $\ge 75\%$ with zero high-severity dark spots)
  - `PROCEED_WITH_CAUTION` (Trust $50\% - 74\%$ with minor caveats)
  - `VERIFY_FIRST` (Trust $< 50\%$ or active critical information gaps)
- **Prioritized Verification Checklist**: Generates a tiered, actionable checklist (`[CRITICAL]`, `[IMPORTANT]`, `[ROUTINE]`) guiding the user on what specific official portals to verify before executing their action.

### Backend
- **Framework**: Python 3.11+ / FastAPI

## 🚀 Deployment Guide (Vercel & Local)

### Option A: 1-Click Vercel Serverless Deployment (Recommended)

This repository includes a pre-configured `vercel.json` routing all API and static requests through `@vercel/python`:

1. Push this repository to your GitHub account:
   ```bash
   git add .
   git commit -m "feat: complete Kazama Protocol"
   git push origin main
   ```
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"** → Import your repository.
3. In **Settings → Environment Variables**, add your keys:
   - `GEMINI_API_KEY`: Your Google Gemini API Key.
   - `TAVILY_API_KEY`: Your Tavily Search API Key.
   - `MOCK_MODE`: `false` (or `true` if running without live search).
4. Click **Deploy**. Vercel will build the serverless functions and serve the frontend at your custom `.vercel.app` domain!

---

### Option B: Local Development Setup

#### 1. Clone the repository
```bash
git clone https://github.com/your-username/kazama-protocol.git
cd kazama-protocol
```

#### 2. Create and activate a virtual environment
```bash
python -m venv .venv

# Windows:
.venv\Scripts\activate

# macOS / Linux:
source .venv/bin/activate
```

#### 3. Install dependencies
```bash
pip install -r requirements.txt
```

#### 4. Configure environment variables
Create a `.env` file in the project root:
```env
GEMINI_API_KEY=your_gemini_api_key_here
TAVILY_API_KEY=your_tavily_api_key_here
MOCK_MODE=false
MOCK_LLM=false
LLM_MODEL=gemini-3.5-flash
LOG_LEVEL=INFO
```

#### 5. Launch the local server
```bash
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

#### 6. Open the application
Navigate to `http://127.0.0.1:8000` in your web browser.

## ⚡ Latency & Vercel Execution Architecture

- **Vercel Serverless Limits**:
  - Vercel Hobby Free Tier imposes a max function execution duration of **60 seconds** (`maxDuration: 60` in `vercel.json`).
  - **Kazama Protocol Real-World Benchmark**: The entire 4-stage pipeline (Tavily search crawl + AI text forensics + Google Gemini 3.5 Flash synthesis) executes in **4 to 8 seconds** — safely well below the serverless threshold!
- **Zero-Timeout Client-Side State Architecture**:
  - Once `/api/analyze` finishes, all parsed sources, facts, conflicts, and dark spots are retained in client memory (`state.lastAnalysis`).
  - **You can wait 1 minute, 10 minutes, or 2 hours before hitting the "Evaluate" button**; there is zero dangling server connection or session expiration.
  - When you evaluate, a lightweight `/api/decide` request executes in **1 to 2.5 seconds**, appending cleanly to your multi-decision ledger!
